The first time you open your copy, a **Read Me First** sheet walks you through a one-time script authorization. You must complete this before the [Startup Wizard](/ue26/startup-wizard/) will run.

## Step 1: Authorize the Script to Run (One-Time Only)

You must perform the following steps for Ultimate Envelopes to work properly.

## Step 2: Open Apps Script

Open the **Extensions → Apps Script** menu to enter the script editor, then select the top file named `RunFirst.gs`.

{% include figure image_path="/assets/images/getting-started-step2.jpg" alt="Extensions menu open, showing the Apps Script option" caption="Extensions → Apps Script" %}

## Step 3: Run the "runFirst" Function

{% include figure image_path="/assets/images/getting-started-step3.jpg" alt="Apps Script editor showing the Run button and the runFirst function" caption="Run the runFirst function" %}

## Step 4: Authorize the Script to Run

You'll see the following prompt.

{% include figure image_path="/assets/images/getting-started-step4.jpg" alt="Authorization required prompt with Review Permissions and Cancel buttons" caption="Authorization required" %}

## Step 5: Click the Link at the Bottom of the Pop-Up

It says "unsafe," but it's safe — this warning appears because the script isn't published on the Google Marketplace, not because of any actual risk.

{% include figure image_path="/assets/images/getting-started-step5.jpg" alt="Google unverified app warning with the Go to Copy of Envelope (unsafe) link highlighted" caption="Click the \"Go to... (unsafe)\" link" %}

## Step 6: Choose the Account You Want to Authorize

Then click **Authorize**.

{% include figure image_path="/assets/images/getting-started-step6.jpg" alt="Google account picker to authorize the script" caption="Choose an account" %}

## Step 7: After the Script Is Done Running

Refresh your sheet and the Startup Wizard will run.

---

**Note:** After the script runs, it will hide this Read Me First sheet.
